# 🧠 To-Do Task Manager

A simple, modern task manager built with React + TailwindCSS.  
It lets you add, delete, and mark tasks complete — with LocalStorage support.

## 🚀 Features
- Add / delete / complete tasks  
- Auto-save locally  
- Progress bar  
- Responsive & clean UI  

## 🧩 Stack
React + TailwindCSS + LocalStorage
